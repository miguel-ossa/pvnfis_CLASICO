PVNFIS — Universal fiscal printer interface for DOS. C++ program that communicates with fiscal 
  ▎ printers via serial port (COM/IRQ) using a file-based command queue. Supports multiple country 
  ▎ formats (Poland, Hungary, Turkey, Portugal, Brazil). Includes PVNFIS.EXE for printer 
  ▎ communication and PVNLET.EXE for number-to-words conversion. Originally written by Miquel de la 
  ▎ Ossa (2000–2001), compilable with MSVC 1.52 and Borland C++ 3.0.
